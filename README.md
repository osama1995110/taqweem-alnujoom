# تقويم النجوم — تطبيق أندرويد

تطبيق أندرويد يعرض تقويم النجوم (الطوالع / منازل القمر الـ28) بشكل بارز، ومعه:
- التاريخ الهجري (أم القرى) والميلادي بالعربي والسرياني
- تقاويم هجرية متعددة: أم القرى، الحسابي، الفلكي، مع تعديل يوم أو يومين حسب رؤية الهلال
- مواقيت الصلاة بثماني طرق حساب (أم القرى، رابطة العالم الإسلامي، المصرية، كراتشي، الكويت، قطر، دبي، أمريكا الشمالية)، مع إشعار عند دخول وقت كل صلاة
- تحديد الموقع تلقائياً من GPS الجوال مع اسم المدينة، أو اختيار مدينة يدوياً
- اتجاه القبلة بالبوصلة
- المصحف كاملاً داخل التطبيق ويعمل بدون إنترنت
- المسبحة بوضعين: أذكار الصلاة (33 لكل ذكر مع هزة عند كل 33)، والأذكار العامة (عدد مفتوح مع هزة كل 100)

برمجة وتصميم: أسامة أبو زيد.

يعمل التطبيق كاملاً بدون إنترنت.

## طريقة بناء ملف APK

### الطريقة الأولى: GitHub (بدون تثبيت أي برنامج)
1. أنشئ حساباً على github.com إن لم يكن لديك.
2. أنشئ مستودعاً جديداً (New repository) وارفع فيه كل محتويات هذا المجلد (Add file ← Upload files)، مع الحفاظ على المجلدات كما هي، بما فيها مجلد `.github`.
3. افتح تبويب **Actions** في المستودع، ستجد عملية "Build APK" تعمل تلقائياً (5 دقائق تقريباً).
4. بعد انتهائها بعلامة ✓ افتحها، وحمّل الملف من قسم **Artifacts** باسم `taqweem-alnujoom-apk`.
5. فك الضغط وانقل `app-debug.apk` إلى الجوال وثبّته (اسمح بالتثبيت من مصادر غير معروفة).

### الطريقة الثانية: Android Studio
1. ثبّت Android Studio وافتح هذا المجلد (Open).
2. انتظر انتهاء المزامنة، ثم من القائمة: Build ← Build App Bundle(s) / APK(s) ← Build APK(s).
3. ستجد الملف في `app/build/outputs/apk/debug/app-debug.apk`.

مهم: قبل البناء في Android Studio شغّل الأمر `python3 tools/fetch_quran.py` مرة واحدة (مع اتصال بالإنترنت) لتحميل نص المصحف داخل التطبيق. في طريقة GitHub يتم ذلك تلقائياً.

## ملاحظات
- عند أول تشغيل اسمح للتطبيق بالإشعارات، واضغط "موقعي" واسمح بالموقع لضبط المواقيت والقبلة بدقة.
- الإشعارات تُجدول لمدة 30 يوماً، وتتجدد تلقائياً كلما فتحت التطبيق.
- صوت الإشعار هو صوت الجوال الافتراضي. لإضافة صوت أذان يلزم ملف صوتي يُضاف إلى `res/raw`.
- تواريخ النجوم ثابتة على التقويم الميلادي حسب الجدول المتداول في الجزيرة العربية (الثريا 7 يونيو، الوسم 16 أكتوبر، المربعانية 7 ديسمبر...).
